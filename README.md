# Foodmania
[![FoodMania Logo](https://www.apnafoodmania.com/logo.png)](https://www.apnafoodmania.com/)

Welcome to FoodMania Restaurant!

Looking for a hassle-free food ordering experience? Look no further! With FoodMania Restaurant, you can easily view restaurants, select delicious food items, and place orders for free delivery, all from the comfort of your home.

Features:

- View restaurants and their menus
- Select your favorite food items
- Place orders and pay on delivery
- Free delivery on all orders
- Login/Signup to save your favorite restaurants and food items

This website is fully dependent on JSON data for easy and efficient data retrieval. Developed by **David Micah-Daniels** using React, without any CSS frameworks, this website is designed to be simple, user-friendly, and efficient.
